Volumio Remote — CYD Install

Flash your 2.8" CYD (Cheap Yellow Display) with the Volumio Remote firmware directly from your browser. No Arduino IDE required.

This installer needs the Web Serial API, which is only available in Chrome or Edge on desktop. Please open this page in one of those browsers.
Before you start:
  1. Connect your CYD board to this computer with a USB data cable (not charge-only).
  2. Click "Connect & Install" above, then choose the correct serial port from the browser prompt.
  3. The tool will erase the board and flash the selected firmware automatically.
  4. Once it finishes, the board will reboot into Volumio Remote.
Having trouble? Check the project README for manual flashing instructions.
